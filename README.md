# Project B2: Dynamic Mood Mapping Agent
**物理音響バイナリから感性コンテキストへの「動的中間マッピングレイヤー」自律生成エージェント**

## 1. 概要
ローカルの音声ファイル（.mp3）から音響物理特徴量（BPM、スペクトル重心、実効音圧など）を直接抽出し、LLMがその数値とジャンル文脈から**「中間感性マッピング（Dynamic Mood Mapping Layer）」を動的に自律構築**する次世代型AIエージェントです。
固定概念に囚われない柔軟な感性工学変換を行い、最適な利用シーンや演出コンテキストを自動選定・レポート化します。

## 2. 想定ユーザーと業務課題
- **想定ユーザー**: 映像制作ディレクター、イベント演出家、広告代理店、音楽プロデューサー、ゲームサウンダーなど、感性的な選曲・比較提案を行うプロフェッショナル。
- **業務課題**: 大量のサンプル音源から演出意図に合致する楽曲を選定する際、選択理由が担当者の「主観・感覚頼み」になりやすく、クライアントや制作チームへの客観的・論理的な説明が困難である点。
- **導入効果**: 物理音響データ（客観的エビデンス）と、LLMが自律生成する感性工学レイヤー（演出効果）を統合することで、**提案レポート作成時間を大幅削減**。説得力のある論理的選曲プレゼンテーションを即座に実現します。

4-2.  処理フロー（ReAct ループの最適化）
1.	タスク受領とフォルダ選択: ユーザーが解析したい楽曲カテゴリ（フォルダ）を選択。
2.	統合ツール実行 (fetch_and_analyze_track):
o	安全な Sandbox（パス検証）を経由し、対象フォルダから 1曲をランダム抽出。
o	バイナリバッファ解析から、BPMおよびスペクトル重心（音の明瞭度・明るさ）を一括算出。
3.	動的中間マッピングレイヤーの生成:
o	抽出された物理数値を受け、LLMが「数値 ➔ 3段階の感性ベクトル」の変換ルールをその場で自律生成。
4.	構造化レポートの出力:
o	物理解析表、動的生成された中間マッピング表、推奨コンテキスト（利用シーン）、総括コメントを1度のターンで一括生成。

## 6. 技術的・業務的な工夫点 (Highlights)
 技術面の工夫
•	自律的中間マッピングレイヤー（Dynamic Mood Mapping Layer）の導入: 従来型の「固定ルールによる変換」を排除。LLM自身に音響物理量（BPM・周波数）とジャンルコンテキストを提示し、中間評価層（3段階マッピング）をリアルタイムに自律定義させることで、あらゆる音楽ジャンルに対応できる汎用性を獲得しました。
•	MCPツールの統合とReActサイクルの極小化（API制限・コスト対策）: 「トラック取得」と「物理解析」を単一の統合MCPツール（fetch_and_analyze_track）へ集約。LLMとのやり取りを最少2ステップに抑えることで、APIレート制限（429 / 503）の回避と応答速度の大幅な向上を実現しました。
•	Strict Directory Traversal Protection (Sandbox): validateAndResolvePath 関数による徹底したパス検証機構を実装。外部や親ディレクトリへの意図しないアクセスを防止する強固なセキュリティ境界を設けています。
•	堅牢なリトライ＆バックオフ機構: callWithRetry 関数により、API高負荷時や制限検知時に指数関数的バックオフ（Wait & Retry）を自動実行し、システムの不意のクラッシュを防止。

業務面の工夫
•	「主観的な感性」の定量的・論理的言語化: 単に「良い曲」「盛り上がる曲」とするのではなく、BPMや音圧・明瞭度といった物理的エビデンスを軸に感性へ変換するため、クライアントへのプレゼンテーション資料としてそのまま活用可能です。
